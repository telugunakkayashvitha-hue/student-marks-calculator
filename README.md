# Student Marks Calculator

A beginner-friendly student project built with **HTML, CSS, and JavaScript**.

## Features
- Enter a student's name and marks in five subjects
- Calculates total marks, average, and percentage
- Assigns a grade based on percentage
- Shows Pass only when every subject mark is at least 35
- Validates marks between 0 and 100
- Responsive layout for mobile and desktop

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the student name and marks.
4. Click **Calculate Results**.

## Subjects
Mathematics, Science, English, Computer Science, and Social Studies. Each subject is out of 100, so the total is out of 500.

## Grade scale
- 90–100%: A+
- 80–89.99%: A
- 70–79.99%: B
- 60–69.99%: C
- 50–59.99%: D
- 35–49.99%: E
- Below 35%: F

> Note: This is a sample grading scale for the project. Change it to match your institution's rules if needed.
